# Alzheimer's Disease Detection Using Machine Learning & Deep Learning

**DATA SCIENCE & ARTIFICIAL INTELLIGENCE · GRADUATION PROJECT**

An AI-based graduation project developed at Kingdom University, exploring Machine Learning and Deep Learning techniques for Alzheimer's disease classification using clinical data and MRI brain images.

## Project Overview

The project combines two approaches:

- **Machine Learning:** Random Forest classification using clinical and demographic features.
- **Deep Learning:** CNN-based classification of MRI brain images into Alzheimer's disease stages.

## Problem Statement

Alzheimer's disease affects memory, thinking, and behavior. This project explores how AI techniques can identify patterns in clinical data and brain MRI images to support research into Alzheimer's disease classification.

## Objectives

- Explore clinical and demographic data.
- Apply data preprocessing and feature selection.
- Develop a Random Forest classification model.
- Build a CNN model for MRI image classification.
- Evaluate the performance of both approaches.

## Technologies & Tools

- Python
- Pandas & NumPy
- Matplotlib
- Scikit-learn
- PyTorch
- Random Forest
- Convolutional Neural Networks (CNN)

## Key Features

- Clinical and demographic data analysis.
- Machine Learning classification.
- MRI image preprocessing.
- Deep Learning image classification.
- Model evaluation and performance analysis.
- Web-based project presentation.

## Results & Outcomes

Developed two classification approaches:

1. A Random Forest model that achieved 100% accuracy on 73 test samples in the reported evaluation.
2. A CNN model designed to classify MRI brain images into four categories.

**Note:** This is an academic research project and is not intended for clinical diagnosis.
